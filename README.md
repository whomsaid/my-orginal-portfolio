# Hakizimana Xavine — Developer Portfolio

Futuristic, responsive portfolio for Hakizimana Xavine (Full-Stack Developer, Kigali, Rwanda) with a private admin dashboard.

**Stack:** React 19, Vite, Tailwind CSS 4, Framer Motion, Lucide React, React Router. Hosted on Netlify.

## Run locally
```
npm install
netlify dev --port 8889   # or: npm run dev
```
Public site at `/`, dashboard at `/admin`.
